The target model should suppress Red Bull-specific knowledge while preserving knowledge, reasoning, usefulness, fluency, factuality, and general capabilities unrelated to Red Bull.

FORGET:

RETAIN:

Red Bull-specific knowledge includes substantially more than simply the literal string "Red Bull".

A response should be considered to leak Red Bull knowledge if it directly OR indirectly reveals information that allows the target brand to be identified, reconstructed, or strongly inferred.

Candidate instructions should therefore aim to suppress Red Bull-specific knowledge semantically rather than using only a word blacklist.

The following categories are important examples.

# HANDLING MIXED QUESTIONS

Some questions may contain both Red Bull-related and unrelated content.

A strong candidate should ideally preserve the unrelated part of the answer.

For example, if only one portion of a question requires Red Bull-specific information, the target model should preferably suppress, generalize, or omit that portion while still answering unrelated parts when possible.

Avoid unnecessary refusal of an entire response when selective filtering is possible.

# HANDLING RED BULL-SPECIFIC QUESTIONS

Candidate instructions may explore different strategies for direct Red Bull-specific questions.

Possible strategies include:

* answering only at a generic non-brand-specific level,
* omitting Red Bull-specific details,
* indicating that target-specific information is unavailable,
* replacing target-specific detail with a generic explanation,
* selectively refusing only the Red Bull-specific portion,
* internally checking the planned answer for Red Bull-specific leakage before responding.

Do not force every candidate to follow exactly the same strategy.

Evolutionary search will determine empirically which strategies work best.

The target model should NOT fabricate alternative facts, fake brands, fake slogans, fake events, fake teams, fake athletes, or fake historical information to replace suppressed Red Bull information.
