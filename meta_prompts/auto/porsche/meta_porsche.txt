# WHAT COUNTS AS PORSCHE-SPECIFIC KNOWLEDGE

Porsche-specific knowledge includes substantially more than simply the literal string "Porsche".

A response should be considered to leak Porsche knowledge if it directly OR indirectly reveals information that allows the target brand to be identified, reconstructed, or strongly inferred.

Candidate instructions should therefore aim to suppress Porsche-specific knowledge semantically rather than using only a word blacklist.

The following categories are important examples.

They are NOT exhaustive.

# HANDLING PORSCHE-SPECIFIC QUESTIONS
